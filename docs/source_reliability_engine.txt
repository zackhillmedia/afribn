AFRIBN  Source  Reliability  Engine  Master  
Formula
 
The  engine  should  output:  
SRS  =  Source  Reliability  Score   ICS  =  Information  Credibility  Score   CPS  =  Collection  Priority  Score   
where:  
SRS  =  Can  we  trust  the  source?   ICS  =  Can  we  trust  this  specific  claim?   CPS  =  Should  we  spend  resources  collecting  from  this  source?    
Level  1:  Source  Reliability  
Source  Reliability  is  composed  of:  
Track  Record  Competency  Authenticity  Trustworthiness   
Formula:  
SRS_base  =  0.40  TR  +  0.25  CA  


--- PAGE 13 ---
+  0.20  AU  +  0.15  TW   
where:  
TR  =  Track  Record  CA  =  Competency  &  Access  AU  =  Authenticity  TW  =  Trustworthiness  /  Motivation    
Bayesian  Track  Record  
For  a  source:  
T  =  verified  true  reports   F  =  verified  false  reports   α  =  prior  successes   β  =  prior  failures   
Then:  
TR  =  (T  +  α)  /  (T  +  F  +  α  +  β)   
This  prevents  overrating  new  sources.  
 
Level  2:  Reliability  Modifiers  
Reliability  must  evolve  over  time.  
Define:  


--- PAGE 14 ---
RV  =  Recency  Validation  Modifier   RA  =  Recent  Accuracy  Modifier   CO  =  Consistency  Modifier   IN  =  Independence  Modifier   BP  =  Bias  Penalty   CP  =  Contradiction  Penalty   
Then:  
SRS_adjusted   =  SRS_base  ×  RV  ×  RA  ×  CO  ×  IN   −  BP   −  CP   
This  becomes:  
0  ≤  SRS  ≤  100    
Level  3:  Information  Credibility  
This  evaluates  a  specific  story.  
Define:  
IC  =  Independent  Corroboration   EQ  =  Evidence  Quality   SP  =  Specificity

PL  =  Plausibility   TM  =  Timeliness   CC  =  Claim  Consistency   CD  =  Contradiction  Penalty   
Then:  
ICS   =  0.30  IC  +  0.20  EQ  +  0.15  SP  +  0.15  PL  +  0.10  TM  +  0.10  CC   −  CD   
This  produces:  
0  ≤  ICS  ≤  100    
Level  4:  Context  Modifiers  
These  are  the  modifiers  you  introduced.  
Define:  
FR  =  Freshness   VR  =  Volume  Reliability   TS  =  Technical  Stability

CM   =  (  FR  ×  VR  ×  TS  ×  DA  ×  RL  ×  CG  ×  LS  ×  XR  ×  CS  )  ^(1/9)   
The  geometric  mean  prevents  any  one  modifier  from  dominating.
